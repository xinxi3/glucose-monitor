# 血糖监测管理系统（患者端）
## 项目介绍
本项目是基于 SpringBoot + HTML + ECharts 开发的血糖监测与健康管理平台患者端，主要用于患者查看个人信息、血糖数据、血糖趋势图表、健康趋势分析、随访计划以及自主上报血糖数据。

系统界面简洁美观，功能完整，图表联动真实数据，适合课程设计、毕业设计及实际项目使用。

---

## 功能模块
### 1. 用户登录与身份验证
- 支持账号密码登录
- 登录成功后将用户信息存入 Session
- 前端通过接口获取当前登录用户信息
- 未登录自动跳转登录页

### 2. 个人信息展示
- 显示患者 ID、姓名、账号、角色
- 显示所属科室、健康状态

### 3. 血糖数据展示（核心功能）
- 展示当前登录患者的血糖历史记录
- 使用 ECharts 折线图展示空腹/餐后血糖趋势
- 自动格式化时间、处理图表显示不全问题
- 图表支持自适应、标签旋转、平滑曲线

### 4. 血糖数据统计
- 平均空腹血糖
- 平均餐后血糖
- 血糖正常次数
- 血糖异常次数
- 自动根据医学标准判断是否正常

### 5. 血糖数据上报
- 支持选择测量类型（空腹/餐后2h）
- 选择监测时间、填写血糖值、填写身体状况
- 提交后自动刷新图表与统计数据

### 6. 诊疗方案展示
- 展示医生制定的诊断结果
- 展示控糖方案、监测频率、主治医生

### 7. 我的随访计划
- 每日血糖监测
- 用药提醒
- 定期复诊
- 医生电话随访
- 饮食指导
- 带状态标签、提示说明，界面美观

### 8. 血糖健康趋势图（双Y轴）
- 空腹血糖曲线
- 餐后血糖曲线
- 健康评分曲线
- 左侧血糖值 + 右侧健康指数
- 与真实数据实时联动

### 后端
- SpringBoot

- MySQL 数据库

- RESTful 接口规范

## 项目文件说明
- patient.html —— 患者个人中心主页面
- 接口说明：
  - /api/login —— 登录接口
  - /api/current —— 获取当前登录用户
  - /api/blood/list —— 获取个人血糖列表
  - /api/blood/submit —— 血糖上报
  - /api/patient/treat/my —— 获取个人诊疗方案

## 运行说明
1. 配置 MySQL 数据库，导入对应数据表（血糖表、用户表、诊疗方案表）
2. 启动 SpringBoot 后端项目，确保接口可正常访问
3. 部署前端页面，直接打开 patient.html 即可
4. 访问登录页，使用患者账号登录
5. 登录成功进入个人中心，使用全部功能

## 使用说明
### 1. 登录系统
1. 打开登录页面，输入账号密码，点击登录
2. 登录成功自动跳转到个人中心
3. 未登录访问页面会自动跳回登录页

### 2. 查看个人信息
1. 登录后默认进入“我的信息”页面
2. 自动展示患者ID、姓名、账号、科室、状态等信息

### 3. 查看血糖图表
1. 点击“我的血糖”标签页
2. 系统自动加载历史血糖数据
3. 展示折线图、统计卡片（平均空腹、平均餐后、正常次数、异常次数）
4. 切换标签自动适配图表大小

### 4. 上报血糖数据
1. 进入“血糖上报”页面
2. 选择测量类型（空腹/餐后2h）
3. 填写测量时间、血糖值、身体状况
4. 点击提交上报
5. 提交成功后自动刷新图表

### 5. 查看诊疗方案
1. 点击“诊疗方案”标签页
2. 查看诊断结果、控糖方案、监测频率、医生信息
3. 无数据时会显示提示文字

### 6. 查看随访计划与健康趋势
1. 点击“我的随访&健康时间轴”
2. 左侧展示完整随访计划
3. 右侧展示血糖健康趋势图（双Y轴）
4. 自动根据患者血糖数据生成健康评分

### 7. 退出登录
1. 点击右上角“设置”
2. 选择“退出登录”
3. 自动清除登录状态并返回登录页
